## 🛠️ Stack

- **Frontend** — Angular (Standalone Components), hosted on AWS S3
- **Backend** — Node.js / Express (RESTful API), hosted on AWS EC2
- **Database** — MongoDB Atlas
- **External APIs** — ExchangeRate-API, frankfurter.app
